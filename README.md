# أرشيف العائلة: النسخة المجانية على GitHub

الموقع كامل يشتغل على **GitHub Pages مجانًا**، بدون سيرفر وبدون أي دفع.

**كيف يبقى خاص والمستودع عام؟** كل الصور والبيانات تتشفّر في جهازك (AES-256) قبل ما تنرفع. اللي ينحفظ على GitHub ملفات مقفولة ما يقدر أحد يفهمها بدون كلمة السر. الزائر يكتب كلمة السر، والمتصفح يفك الصور عنده بس.

رابط الموقع: **https://1097mbnalll-ui.github.io/Archive/**

---

## أول مرة (تسويها مرة وحدة)

### 1) فعّل GitHub Pages

1. افتح https://github.com/1097mbnalll-ui/Archive/settings/pages
2. تحت **Source** اختر **Deploy from a branch**.
3. تحت **Branch** اختر **gh-pages**، والمجلد **/ (root)**، واضغط **Save**.

### 2) سوِّ مفتاح GitHub

هذا المفتاح يسمح للموقع يحفظ صورك في المستودع. ما أحد يحتاجه غيرك.

1. افتح https://github.com/settings/personal-access-tokens/new
2. **Token name:** اكتب `أرشيف العائلة`.
3. **Expiration:** اختر أطول مدة متاحة. لما تنتهي، سوِّ مفتاح جديد بنفس الخطوات.
4. **Repository access:** اختر **Only select repositories**، وبعدها **Archive**.
5. **Permissions ← Repository permissions ← Contents:** اختر **Read and write**.
6. اضغط **Generate token**، وانسخ المفتاح. يبدأ بـ `github_pat_`.

> لا تعطي المفتاح لأحد، ولا تحطه في رسالة.

### 3) جهّز الأرشيف

1. افتح رابط الموقع.
2. بتطلع لك صفحة **تجهيز الأرشيف**. اكتب فيها:
   - **كلمة سر الزوار:** تعطيها للعائلة.
   - **كلمة سر المدير:** لك أنت بس.
   - **مفتاح GitHub:** اللي نسخته في الخطوة 2.
3. اضغط **جهّز الأرشيف**.

خلاص، الحين تقدر ترفع الصور.

## الاستخدام

| | |
|---|---|
| **الدخول** | كلمة سر الزوار تفتح الأرشيف. كلمة سر المدير تفتح كل شي، بما فيها لوحة الإدارة. |
| **لوحة الإدارة** | من الموقع اضغط **لوحة الإدارة**، أو افتح الرابط وزِد عليه `#/admin`. |
| **جهاز جديد للمدير** | أول مرة تفتح اللوحة من جهاز جديد، بيطلب منك مفتاح GitHub. |
| **بعد الحفظ** | التغييرات تظهر للزوار خلال دقيقة أو دقيقتين. |

## وش فيه

- **الموقع:** شكل الخلية. العائلة في النص، وحولها الأشخاص، وتضغط على أي شخص وتطلع ذكرياته.
- **رفع الصور:** تختار صور كثيرة مرة وحدة، وتشوف معاينتها، وتكتب بيانات مشتركة وبيانات لكل صورة.
- **التصغير:** الصور تتصغّر في جهازك قبل ما تنرفع، وتنشال منها معلومات الموقع الجغرافي.
- **الألبومات والمناسبات:** تسويها وتعدّلها وتحذفها.
- **الخصوصية:** كل صورة إما **لكل العائلة** أو **خاصة** (المدير بس). الخاصة تتشفّر بمفتاح ثاني ما يوصله الزوار.
- **المحذوفات:** ما فيه حذف نهائي. أي شي تحذفه يروح هنا وترجعه بضغطة.
- **كلمات السر:** تغيّرها من اللوحة.
- **حماية الصور:** علامة مائية، ومنع الحفظ والنسخ والطباعة، والشاشة تتغطى لما تطلع من الصفحة.

## أشياء لازم تعرفها

- **احتفظ بالصور الأصلية عندك.** الموقع يحفظ نسخة مصغّرة فقط، عشان GitHub Pages له حد حجم (1 جيجا).
- **لو نسيت كلمة سر المدير، الأرشيف ما يقدر أحد يفتحه.** ولا حتى GitHub. اكتبها في مكان آمن.
- **تغيير كلمة سر الزوار** يمنع الدخول بالقديمة من الموقع. بس اللي كان عنده الكلمة القديمة ونسخ الملفات المشفّرة قبل التغيير، يقدر يفكها.
- **تغيير صورة من "لكل العائلة" إلى "خاصة"** يعيد تشفيرها. بس النسخة القديمة تبقى في تاريخ GitHub، فالأفضل تختار الخصوصية وقت الرفع.
- **تصوير الشاشة ما يقدر موقع يمنعه منع كامل.** العلامة المائية تخلي أي صورة منتشرة تبيّن إنها من الأرشيف ومن أي جلسة.

## للمطورين

- الكود في `github-site/`، وينعرض من فرع `gh-pages`. الأرشيف المشفّر في مجلد `vault/` داخل نفس الفرع.
- **اختبار كامل في متصفح:** شغّل `node test/github-site/mock-github.js 4100`، وبعدها `node test/github-site/e2e.js <مجلد صور> <مجلد لقطات>`.
