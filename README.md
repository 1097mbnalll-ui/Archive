# أرشيف العائلة

موقع لحفظ صور العائلة القديمة ومستنداتها وقصصها، ومعه لوحة إدارة.

- **الموقع:** التنقل فيه على شكل خلية. في النص العائلة، وحولها أفرادها، وتضغط على أي شخص وتطلع ذكرياته.
- **لوحة الإدارة (`/admin`):** رفع الصور، وتعديل بياناتها، والألبومات والمناسبات، وحسابات أفراد العائلة.

## التشغيل

يحتاج Node.js نسخة 22.13 أو أحدث.

```
npm install
npm run create-admin -- اسم-المستخدم "الاسم الظاهر"
npm start
```

أمر `create-admin` يسألك عن كلمة السر. بعدها افتح `http://localhost:3000/login`.

> **مهم:** الموقع صار يحتاج سيرفر يشغّل Node.js، فما يشتغل على GitHub Pages.
> كل البيانات والصور محفوظة في مجلد `data/`، وهذا المجلد ما ينرفع على GitHub.
> **خذ نسخة احتياطية من مجلد `data/` بشكل دوري.**

## الصلاحيات

| الصلاحية | وش يقدر يسوي |
|---|---|
| **مدير** | كل شي: يضيف أفراد العائلة ويغيّر صلاحياتهم، ويرفع ويعدّل ويحذف. |
| **محرر** | يرفع الصور ويعدّلها، ويدير الألبومات والمناسبات. |
| **زائر** | يدخل الموقع ويشوف صور العائلة. ما يدخل لوحة الإدارة. |

## الخصوصية

- كل صورة إما **العائلة فقط** (وهذا الافتراضي)، أو **عامة**.
- اللي ما دخل بحسابه يشوف الصور العامة بس، وأسماء الأشخاص اللي فيها بس.
- ملفات الصور ما تنعرض مباشرة: كل طلب يمر على فحص الخصوصية.
- نسخ العرض تنشال منها معلومات الموقع الجغرافي (GPS). الملف الأصلي محفوظ كما هو، وما يحمّله إلا المحرر والمدير.

## الحذف

ما فيه حذف نهائي من اللوحة. أي شي تحذفه (صورة، أو ألبوم، أو حساب) ينتقل إلى **المحذوفات**، وترجعه بضغطة.
