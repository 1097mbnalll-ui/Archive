# أرشيف العائلة

موقع لحفظ صور العائلة القديمة ومستنداتها وقصصها. التنقل فيه على شكل خلية: في النص العائلة، وحولها أفرادها، وتضغط على أي شخص وتطلع ذكرياته حوله.

> **تنبيه مهم:** هذي النسخة **تجريبية** وفيها بيانات وهمية فقط.
> كلمة السر هنا حماية شكلية، وأي شخص يعرف يفتح ملفات الموقع يقدر يتجاوزها. والمستودع عام.
> **لا ترفع أي صورة حقيقية** إلا بعد ما نسوي هذي الخطوتين:
> 1. نحوّل المستودع إلى خاص (private).
> 2. ننقل الموقع إلى Cloudflare مع كلمة سر حقيقية، مثل ما هو في ملف التصميم.

## تجربة الموقع

كلمة السر التجريبية: `1234`

**على جهازك:** افتح مجلد المشروع، وشغّل الأمر:

```
python3 -m http.server 8000
```

وبعدها افتح `http://localhost:8000` في المتصفح.

**على GitHub Pages:**
1. افتح المستودع على GitHub، وادخل **Settings**، وبعدها **Pages**.
2. تحت **Source** اختر **Deploy from a branch**.
3. اختر الفرع اللي فيه الموقع، والمجلد `/ (root)`، واضغط **Save**.
4. بعد دقيقة أو دقيقتين يطلع لك رابط الموقع في نفس الصفحة.

## الملفات

| الملف | وش فيه |
|---|---|
| `data.js` | الأشخاص والصور والقصص. **هذا الملف اللي تعدّل فيه.** |
| `index.html` | هيكل الصفحة. |
| `styles.css` | الألوان والخطوط وشكل الخلية. |
| `app.js` | طريقة عمل الموقع والتنقل. |
| `docs/superpowers/specs/` | ملف التصميم الكامل. |

## إضافة شخص أو ذكرى (في النسخة التجريبية)

في `data.js`:

- **شخص جديد:** أضف سطر داخل `people`، وله `id` بالإنجليزي بدون مسافات.
- **ذكرى جديدة:** أضف سطر داخل `items`، وفي `people` اكتب الـ `id` حق كل شخص موجود فيها.
- **صورة:** حطها في مجلد `images`، واكتب مسارها في `image`، مثل `'images/wedding-1968.jpg'`.

## تغيير كلمة السر التجريبية

1. احسب بصمة SHA-256 لكلمة السر الجديدة، بأي أداة على الإنترنت أو بالأمر:
   ```
   printf 'كلمة-السر' | sha256sum
   ```
2. حط البصمة في `passwordHash` داخل `data.js`.
