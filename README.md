# أرشيف العائلة

موقع لحفظ صور العائلة القديمة ومستنداتها وقصصها، ومعه لوحة إدارة.

- **الموقع:** التنقل فيه على شكل خلية. في النص العائلة، وحولها أفرادها، وتضغط على أي شخص وتطلع ذكرياته.
- **لوحة الإدارة (`/admin`):** رفع الصور، وتعديل بياناتها، والألبومات والمناسبات، وحسابات أفراد العائلة.

## التشغيل

يحتاج Node.js نسخة 22.13 أو أحدث.

```
npm install
npm run set-password -- visitor     # كلمة سر الزوار
npm run set-password -- admin       # كلمة سر المدير
npm start
```

كل أمر يسألك عن كلمة السر. بعدها افتح `http://localhost:3000`.

تقدر بعد تسوي حساب خاص لمدير باسمه: `npm run create-admin -- اسم-المستخدم "الاسم الظاهر"`.

## الدخول

**الموقع كامل مقفول.** ما ينفتح شي بدون كلمة سر. فيه ثلاث طرق للدخول:

| الطريقة | وش تفتح |
|---|---|
| **كلمة سر الزوار** (مشتركة) | الموقع بس. ما تشوف الصور "الخاصة". |
| **كلمة سر المدير** (مشتركة) | كل شي، بما فيها لوحة الإدارة. |
| **حساب خاص** (اسم + كلمة سر) | حسب صلاحية الحساب. |

تغيّر كلمات السر المشتركة أو توقفها من **لوحة الإدارة ← كلمات السر**. أي تغيير يطلّع كل اللي دخلوا بالكلمة القديمة.

> **مهم:** الموقع صار يحتاج سيرفر يشغّل Node.js، فما يشتغل على GitHub Pages.
> كل البيانات والصور محفوظة في مجلد `data/`، وهذا المجلد ما ينرفع على GitHub.
> **خذ نسخة احتياطية من مجلد `data/` بشكل دوري.**

## الصلاحيات

| الصلاحية | وش يقدر يسوي |
|---|---|
| **مدير** | كل شي: يضيف أفراد العائلة ويغيّر صلاحياتهم، ويرفع ويعدّل ويحذف. |
| **محرر** | يرفع الصور ويعدّلها، ويدير الألبومات والمناسبات. |
| **زائر** | يدخل الموقع ويشوف صور العائلة. ما يدخل لوحة الإدارة. |

## الخصوصية

- كل صورة إما **لكل العائلة** (وهذا الافتراضي)، أو **خاصة**: يشوفها أصحاب الحسابات الخاصة وكلمة سر المدير بس.
- ملفات الصور ما تنعرض مباشرة: كل طلب يمر على فحص الدخول والخصوصية.

## حماية الصور من النسخ

> **تنبيه صريح:** ما فيه موقع يقدر يمنع تصوير الشاشة منع كامل، ولا يمنع أحد يصوّر الشاشة بجوال ثاني.
> الحمايات هنا تسكّر الطرق السهلة، والعلامة المائية تخلي أي صورة منتشرة تفضح مصدرها.

- **علامة مائية:** فوق كل الصفحات فيها اسم الداخل، ورمز جهازه، والتاريخ. الرموز وأجهزتها تطلع في **لوحة الإدارة ← كلمات السر**.
- **منع الحفظ والنسخ:** ما فيه زر يمين، ولا ضغط مطوّل لحفظ الصورة، ولا سحب، ولا تحديد، ولا نسخ، ولا اختصارات الحفظ والطباعة.
- **الصور ما تنفتح لحالها:** فتح رابط الصورة في تبويب جديد ممنوع، والصور ما تنحفظ في ذاكرة المتصفح.
- **تغطية الصفحة:** الصفحة تتغطى لما تطلع منها، أو تفتح قائمة التطبيقات في الجوال، أو تضغط أزرار التصوير المعروفة في الكمبيوتر.
- **منع الطباعة:** الطباعة تطلع صفحة فاضية.
- نسخ العرض تنشال منها معلومات الموقع الجغرافي (GPS). الملف الأصلي محفوظ كما هو، وما يحمّله إلا المحرر والمدير.

## الحذف

ما فيه حذف نهائي من اللوحة. أي شي تحذفه (صورة، أو ألبوم، أو حساب) ينتقل إلى **المحذوفات**، وترجعه بضغطة.
